## 三、角色召唤规则（继承12-引导秘书逻辑）

### 3.1 强度分级

| 强度 | 描述 | 适用场景 | 角色数 |
|------|------|---------|-------|
| 轻量 | 快速咨询 | 简单问答、信息查询 | 1-2 |
| 标准 | 标准协作 | 功能开发、Bug修复、中等复杂度 | 3-5 |
| 全面 | 全系统推演 | 架构决策、跨系统变更、重大风险 | 6-10 |

### 3.2 召唤规则

```
规则1: 意图匹配 → 从15组路由关键词命中目标子系统 → 从子系统查角色注册表
规则2: 复杂度定级 → 轻量/标准/全面 → 决定角色数量和强度
规则3: 冲突消解 → 当两个角色给出冲突建议 → 总控裁决（或沙盘重演）
规则4: 死锁处理 → 锁定>3轮 → 提升到全面强度 + 引入风险审计员
规则5: 超时保护 → 连续3次死锁 → 输出当前状态YAML + 建议终止/人工介入
```

### 3.3 角色召唤命令格式

```
[召唤角色:角色名]
目的: xxx
上下文: xxx
输入: xxx
期望输出: xxx
```
