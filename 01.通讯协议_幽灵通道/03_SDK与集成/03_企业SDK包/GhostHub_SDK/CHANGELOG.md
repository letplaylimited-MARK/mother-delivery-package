# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-15

### Added
- **Intention Bank**: Complete intent parsing system with 22+ business templates
  - HR workflows: recruitment, onboarding, performance review
  - IoT controls: smart home, industrial automation
  - Operations: reporting, monitoring, alerts
  - Finance: invoicing, expense tracking
- **No-UI Adapter**: IoT device integration framework
  - Protocol support: MQTT, HTTP, WebSocket, CoAP
  - Device categories: smart_home, industrial, wearable, automotive
  - Command conversion and execution
- **Agent Federation**: Multi-agent collaboration system
  - Agent discovery and routing
  - Cooperative task execution
  - Session management

### Features
- Modular architecture with optional component installation
- Enterprise-grade configuration system
- Task graph generation for complex workflows
- Workflow execution with progress tracking
