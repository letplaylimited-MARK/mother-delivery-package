# SDK 与集成

## 三套 SDK 定位

| SDK | 路径 | 语言 | 适合场景 |
|-----|------|------|---------|
| **企业 SDK** | `03_企业SDK包/GhostHub_SDK/` | Python | 完整功能（agent federation、intention bank），适合企业级部署 |
| **轻量对接 SDK** | `04_SDK工程包/ghost-channel-sdk/` | Python + TypeScript | 协议层对接，轻量快速整合 |
| **开源社区版** | `02_开源社区包/ghost_channel开源库/` | Python | MIT 授权，核心协议实现，社区贡献 |

## 行业模板

`03_企业SDK包/GhostHub_SDK/templates/` 包含 23 个开箱即用场景（HR、IoT、金融、电商...）。
