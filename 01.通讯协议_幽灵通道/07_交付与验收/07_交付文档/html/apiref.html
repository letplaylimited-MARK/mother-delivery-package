GET /v1/channels

获取所有频道列表

响应

{
  "channels": [
    { "id": "ch_abc123", "name": "general", "type": "broadcast", "created_at": "2026-04-15T10:00:00Z" }
  ]
}
字段类型描述
idstring频道唯一标识符
namestring频道名称
typestring类型: broadcast | multicast | unicast
POST /v1/channels

创建新频道

请求体

{
  "name": "my-channel",
  "type": "broadcast",
  "retention": { "max_messages": 10000 }
}

响应

{
  "id": "ch_xyz789",
  "name": "my-channel",
  "type": "broadcast",
  "created_at": "2026-04-15T10:00:00Z"
}
POST /v1/messages

发布消息到频道

请求体

{
  "channel_id": "ch_abc123",
  "payload": { "text": "Hello World" },
  "compression": "zstd"
}

响应

{
  "id": "msg_123",
  "channel_id": "ch_abc123",
  "timestamp": "2026-04-15T10:00:00.000Z",
  "size_bytes": 256
}
GET /v1/messages

拉取频道消息（短轮询）

查询参数

参数类型描述
channel_idstring频道ID
cursorstring游标分页
limitinteger返回数量 (默认50)
DELETE /v1/channels/{id}

删除频道及其所有消息

GET /v1/stats

获取运行时统计信息

响应

{
  "channels": 150,
  "messages_per_second": 12450,
  "active_subscribers": 3200,
  "cache_hit_rate": 0.998
}
SDK封装：推荐使用Python/TypeScript SDK，它们自动处理认证、重试、压缩等细节。
查看 使用指南 获取SDK示例。
