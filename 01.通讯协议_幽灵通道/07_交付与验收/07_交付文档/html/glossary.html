核心概念

Channel 频道

消息传输的逻辑管道，支持广播、多播、单播三种模式

Message 消息

在频道中传输的数据单元，包含payload和元数据

Subscriber 订阅者

订阅频道以接收消息的客户端

Publisher 发布者

向频道发送消息的客户端

协议术语

Cursor 游标

用于分页查询的位置标记，支持双向遍历

Compression 压缩

支持zstd、gzip、lz4算法，自动协商最佳压缩比

Retention 保留策略

控制消息存储时长和最大数量

性能指标

P99 Latency P99延迟

99%请求的响应时间，目标值 <10ms

Throughput 吞吐量

系统处理消息的速率，目标值 >10,000 msg/s

Cache Hit Rate 缓存命中率

Redis缓存命中比例，目标值 >99%

部署相关

Docker Compose Docker编排

定义和运行多容器Docker应用的工具

Environment Variables 环境变量

配置服务行为的键值对，如GHOST_HUB_PORT、GHOST_HUB_REDIS_URL
