Python SDK 安装

方式一：pip 安装（推荐）

pip install ghost-channel-sdk

✓ 安装成功验证

python -c "from ghost_channel_sdk import GhostChannelSDK; print('OK')"

方式二：本地安装（开发模式）

1. 克隆 SDK 仓库

git clone https://github.com/ghost-channel/python-sdk.git
cd python-sdk

2. 安装依赖并设置开发模式

pip install -e .

3. 验证安装

python -m pytest tests/ -v

TypeScript SDK 安装

方式一：npm 安装（推荐）

npm install ghost-channel-sdk

方式二：本地安装（开发模式）

1. 克隆 SDK 仓库

git clone https://github.com/ghost-channel/typescript-sdk.git
cd typescript-sdk

2. 安装依赖

npm install

3. 运行测试

npm test

Docker 部署

快速启动

# 拉取镜像
docker pull ghostchannel/sdk:latest

# 运行交互式示例
docker run -it ghostchannel/sdk:latest python stress_test_100_concurrent.py

使用 Docker Compose

docker-compose up --build

验证安装

Python SDK 验证

python -c "
import asyncio
from ghost_channel_sdk import GhostChannelSDK, GhostChannelConfig

async def test():
    sdk = GhostChannelSDK(GhostChannelConfig())
    result = await sdk.sync_memory_delta(
        'agent_a', 'agent_b',
        {'v': 'v1', 'data': 1},
        {'v': 'v2', 'data': 2}
    )
    print(f'Success: {result.success}')
    print(f'Bandwidth reduction: {result.bandwidth_reduction:.1%}')
    print(f'Latency: {result.latency_ms:.2f}ms')

asyncio.run(test())
"

预期输出：Success: True, Bandwidth reduction: XX%, Latency: Xms

TypeScript SDK 验证

npx ts-node -e "
import { GhostChannelClient } from 'ghost-channel-sdk';

const client = new GhostChannelClient({});
const result = await client.syncMemoryDelta(
  'agent_a', 'agent_b',
  { v: 'v1', data: 1 },
  { v: 'v2', data: 2 }
);
console.log('Success:', result.success);
console.log('Bandwidth reduction:', result.bandwidthReduction);
"

常见问题

⚠️ 依赖问题
如果遇到 cryptography 或其他依赖安装失败，请确保系统已安装 OpenSSL 开发库： 
# Ubuntu/Debian
sudo apt-get install libssl-dev

# macOS
brew install openssl
⚠️ 权限问题
如果遇到权限错误，建议使用虚拟环境： 
python -m venv venv
source venv/bin/activate  # Linux/macOS
# 或
.\venv\Scripts\activate  # Windows
pip install ghost-channel-sdk
