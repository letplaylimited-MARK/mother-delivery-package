连接被拒绝 (Connection Refused)

症状：无法连接到Ghost Hub服务
解决方案：
  1. 检查服务是否运行：docker ps | grep ghost-hub
  2. 验证端口未被占用：netstat -an | grep 8080
  3. 检查防火墙设置：允许8080端口入站
  4. 确认环境变量配置正确

消息丢失

症状：发送的消息未被接收
解决方案：
  1. 检查频道ID是否正确
  2. 验证订阅者数量：GET /v1/channels/{id}/subscribers
  3. 确认消息大小未超过限制（默认1MB）
  4. 检查压缩格式是否兼容

性能下降

症状：延迟增加，吞吐量下降
解决方案：
  1. 检查Redis连接：redis-cli ping
  2. 查看统计信息：GET /v1/stats
  3. 考虑增加消息批量大小
  4. 检查网络带宽是否饱和

认证失败

症状：API返回401 Unauthorized
解决方案：
  1. 检查API Key是否设置：echo $GHOST_HUB_API_KEY
  2. 确认API Key未过期
  3. 验证请求头格式：Authorization: Bearer {key}

Docker启动失败

症状：docker-compose up 报错
解决方案：
  1. 清理旧容器：docker-compose down -v
  2. 重新构建：docker-compose build --no-cache
  3. 检查Docker版本：docker --version (需要20.10+)
  4. 查看日志：docker-compose logs -f

诊断命令

# 健康检查
curl http://localhost:8080/v1/health

# 服务统计
curl http://localhost:8080/v1/stats

# Redis连接测试
docker exec -it ghost-hub-redis redis-cli ping

# 查看容器日志
docker-compose logs -f --tail=100
