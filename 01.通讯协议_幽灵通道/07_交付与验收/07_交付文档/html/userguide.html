GhostChannelConfig 配置选项

选项 类型 默认值 说明
compression_level int 9 zlib压缩级别 (0=无, 9=最大)
semantic_threshold float 0.7 语义相关性阈值
audit_enabled bool true 是否记录审计日志
max_retry int 3 失败重试次数
completion_mode str "apply" "apply"(等待APPLIED) 或 "verify"(等待VERIFIED)
await_ack bool false 是否等待ACK确认
ack_timeout_ms int 500 ACK超时时间(毫秒)
replay_window_size int 1024 重放窗口大小

核心 API 方法

sync_memory_delta()

执行两个状态间的增量同步

Python 签名

async def sync_memory_delta(
    self,
    source_role: str,
    target_role: str,
    old_state: dict,
    new_state: dict,
    semantic_filter: str | None = None
) -> SyncResult

TypeScript 签名

async syncMemoryDelta(
    sourceRole: string,
    targetRole: string,
    oldState: Record,
    newState: Record,
    semanticFilter?: string
): Promise<SyncResult>

参数说明

参数 类型 说明
source_role string 源角色标识符
target_role string 目标角色标识符
old_state dict 同步前的状态快照
new_state dict 同步后的状态快照
semantic_filter string|null 可选的语义过滤关键词

返回 SyncResult

class SyncResult:
    success: bool              # 同步是否成功
    bandwidth_reduction: float  # 带宽降低百分比 (0.0-1.0)
    latency_ms: float          # 同步延迟(毫秒)
    consistency_verified: bool # 一致性是否验证
    changes_applied: int       # 应用的变更数量
    errors: list[ErrorObject]  # 错误列表

sync_workflow_state()

同步工作流步骤状态，支持依赖追踪

Python 签名

async def sync_workflow_state(
    self,
    workflow_id: str,
    step_id: str,
    step_state: dict,
    dependencies: list[str]
) -> SyncResult

示例

# 步骤1：无依赖
await sdk.sync_workflow_state(
    "workflow_1", "step_a",
    {"status": "completed"},
    []
)

# 步骤2：依赖步骤1
await sdk.sync_workflow_state(
    "workflow_1", "step_b",
    {"status": "completed"},
    ["step_a"]  # 等待 step_a 完成
)

recover_from_failure()

从快照恢复失败步骤的状态

Python 签名

async def recover_from_failure(
    self,
    step_id: str,
    last_known_state: dict
) -> dict
说明： 如果存在可用的快照记录，返回快照状态；否则返回 last_known_state。

receive_ack()

处理接收到的 ACK 消息

Python 签名

async def receive_ack(self, ack: dict | AckMessage) -> None
注意： ACK 类型必须遵循单调递增规则：RECEIVED → VERIFIED → APPLIED

最佳实践

1. 状态设计

推荐： 将状态组织为嵌套字典结构，便于增量检测
不推荐： 使用数组索引或复杂嵌套结构 
# 推荐
state = {
    "user": {"name": "张三", "preferences": {"theme": "dark"}},
    "data": {"items": [1, 2, 3]}
}

# 不推荐
state = ["user", "zhangsan", ["theme", "dark"]]

2. 版本控制

# 每次状态变更都更新版本号
state = {
    "__version__": "v2",  # 必须包含版本
    "data": new_value
}

3. 列表追加优化

# Ghost Hub 自动检测列表追加模式
# 仅追加元素时，使用 list_appends 节省带宽

# 每次追加而非替换整个列表
interactions.append(new_item)  # ✓ 推荐
interactions = interactions + [new_item]  # ✗ 带宽浪费

4. 并发同步

import asyncio

async def concurrent_sync_demo():
    sdk = GhostChannelSDK()
    
    # 同时同步多个目标
    tasks = [
        sdk.sync_memory_delta("source", f"target_{i}", old_state, new_state)
        for i in range(10)
    ]
    
    results = await asyncio.gather(*tasks)
    print(f"成功: {sum(1 for r in results if r.success)}/{len(results)}")
