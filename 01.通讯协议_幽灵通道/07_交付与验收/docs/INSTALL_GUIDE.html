📋 1. 前置要求

组件最低要求推荐配置
Python3.103.11 / 3.12
内存2GB4GB+
磁盘1GB5GB+
网络必需稳定网络

🚀 2. 安装方式

方式一：pip安装（推荐）

# 安装稳定版
pip install ghost-hub-sdk

# 安装特定版本
pip install ghost-hub-sdk==1.0.0

# 升级到最新版本
pip install --upgrade ghost-hub-sdk

方式二：从源码安装

# 克隆仓库
git clone https://github.com/ghost-hub/sdk.git
cd sdk

# 安装依赖
pip install -e ".[all]"

方式三：Docker安装

# 拉取镜像
docker pull ghosthub/sdk:1.0.0

# 运行容器
docker run -p 8080:8080 ghosthub/sdk:1.0.0

✅ 3. 验证安装

Python验证

import ghost_hub_sdk
print(ghost_hub_sdk.__version__)
# 输出: 1.0.0

快速测试

from ghost_hub_sdk import GhostHubSDK

sdk = GhostHubSDK()
result = sdk.execute_workflow("测试")
print(result)

🔧 4. 问题排查

问题：Python版本不兼容
解决：确保Python版本 >= 3.10
问题：pip安装失败
解决：使用国内镜像
pip install ghost-hub-sdk -i https://pypi.tuna.tsinghua.edu.cn/simple

🐳 5. Docker安装

# docker-compose.yml
version: '3.8'
services:
  ghost-hub:
    image: ghosthub/sdk:1.0.0
    ports:
      - "8080:8080"

# 运行
docker-compose up -d
