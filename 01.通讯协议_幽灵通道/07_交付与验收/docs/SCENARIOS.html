👔 场景1：HR人力资源

适用场景

场景输入示例输出
招聘优化"帮我招聘Python工程师"完整招聘流程
入职办理"新员工入职流程"入职清单+账号创建
绩效考核"年度绩效考核"评估模板+流程

代码示例

from ghost_hub_sdk import GhostHubSDK

sdk = GhostHubSDK()

# 招聘优化
result = sdk.execute_workflow("帮我招聘Python工程师")
print(f"任务列表: {[t['name'] for t in result['task_graph']['tasks']]}")

# 入职办理
result = sdk.execute_workflow("新员工入职流程")
print(f"步骤: {result['task_graph']['task_count']} 步")

🏠 场景2：IoT物联网

适用场景

场景输入示例支持设备
智能家居"离家模式" / "开灯"灯、空调、门锁
工业控制"启动生产线A"PLC、传感器
能源管理"关闭非必要设备"断路器、计量表

代码示例

# 连接IoT网关
sdk.no_ui_adapter.connect(protocol="mqtt")

# 智能家居控制
command = sdk.no_ui_adapter.convert_intent_to_command(
    intent="把客厅灯打开",
    device_type="light"
)
print(f"命令: {command.action}")

# 场景执行
results = sdk.no_ui_adapter.execute_scene("离家模式")
print(f"执行了 {len(results)} 个设备命令")

🤖 场景3：智能体协作

适用场景

场景任务类型协作模式
数据分析ETL、报表并行处理
内容生成文案、设计串行流水线
客户服务FAQ、工单路由分发

代码示例

# 任务分发
task = {
    "name": "销售数据分析",
    "description": "分析Q1销售数据",
    "priority": "high"
}

result = sdk.agent_federation.distribute_task(
    task=task,
    strategy="capability_match"
)
print(f"分配给: {result['agent_id']}")

# 协作会话
session = sdk.agent_federation.create_session(
    session_id="report_generation",
    agents=["data_agent", "viz_agent", "report_agent"]
)
session.start()
