# 三层架构

> **类型**: concept  
> **置信度**: high

---

## 定义

Universal-KB的三层知识架构：

```
Layer 1: 01-raw/      ← 原始资料（不可变）
Layer 2: 03-wiki/    ← 知识图谱（可编辑）
Layer 3: 04-memory/  ← 长期记忆（持久化）
```

## 说明

### Layer 1: 01-raw/
- 存放所有原始输入
- 规则：只读，不修改
- 可放入任何格式文件

### Layer 2: 03-wiki/
- 存放结构化知识
- concepts/ 概念定义
- entities/ 实体定义
- sources/ 源摘要
- comparisons/ 对比分析

### Layer 3: 04-memory/
- MemoryOS引擎驱动
- short_term/ 短期记忆
- mid_term/ 中期记忆
- long_term/ 长期记忆
