## 一、价值体系

### 1.1 核心价值

| 价值 | 说明 | 效果 |
|------|------|------|
| **省时间** | 文件整理自动化 | 1小时 → 5分钟 |
| **记得住** | AI持久记忆 | 永不遗忘 |
| **会学习** | 持续积累进化 | 越用越懂你 |
| **能传承** | 经验可复制 | 随时可查 |

### 1.2 投入产出比

```
投入：
  - 初始设置：5分钟
  - 日常使用：随手放
  - 定期整理：每周5分钟

产出：
  - 找文件：1小时 → 5分钟
  - 整理知识：1小时 → 10分钟
  - 传承经验：不可量化 → 随时可查
```

## 二、功能体系

### 2.1 五大核心功能

| 功能 | 输入 | 输出 | 状态 |
|------|------|------|------|
| **智能检索** | 自然语言查询 | 语义匹配结果 | ✅ |
| **知识摄取** | 01-raw/文件 | 03-wiki/结构化 | ✅ |
| **记忆系统** | 对话/经验 | 长期记忆 | ✅ |
| **健康检查** | "lint" | 诊断报告 | ✅ |
| **知识图谱** | 概念/实体 | 关联索引 | ✅ |

### 2.2 功能详解

**F1: 智能检索** - 语义搜索
```
用户问 → AI理解 → 03-wiki搜索 → 整合回答 → 来源追溯
```

**F2: 知识摄取** - Ingest流程
```
放文件 → 01-raw/ → 提取概念/实体 → 03-wiki/ → log.md
```

**F3: 记忆系统** - MemoryOS
```
短记忆(FIFO) → 中记忆(热度) → 长记忆(持久)
```

**F4: 健康检查** - Lint
```
检查孤立页面 + 断链 + 矛盾 + 过期
```

**F5: 知识图谱** - 结构化管理
```
concepts + entities + sources + comparisons → index.md
```

## 三、结构体系

### 3.1 完整目录

```
Universal-KB/
├── 01-raw/         ← 原始资料
├── 02-processed/   ← 临时数据
├── 03-wiki/        ← 知识图谱（核心）
├── 04-memory/      ← 长期记忆
├── 05-agents/     ← AGENTS配置
├── 06-output/     ← 输出成果
└── docs/          ← 文档
```

### 3.2 数据流

```
用户输入 → 01-raw/
    ↓ Ingest
03-wiki/ → concepts + entities + sources
    ↓ Query
04-memory/ → short + mid + long
    ↓ AGENTS
05-agents/AGENTS.md
    ↓ 输出
06-output/
```

## 四、技术架构

### 4.1 三层架构（核心）

```
Layer 1: 01-raw/     = 原始资料（不可变）
         ↓ Ingest
Layer 2: 03-wiki/    = 知识图谱（可编辑）
         ↓ Query
Layer 3: 04-memory/ = 长期记忆（持久化）
```

### 4.2 MemoryOS引擎

```
ShortTermMemory (FIFO, 7条)
    ↓ 淘汰
MidTermMemory (热度, 1000条)
    ↓ 晋升
LongTermMemory (持久, 100条)
```
