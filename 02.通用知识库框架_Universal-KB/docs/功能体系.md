| # | 功能 | 输入 | 输出 | 状态 |
|---|------|------|------|------|
| F1 | **智能检索** | 自然语言查询 | 语义匹配结果 | ✅ |

---

## 功能详解

### F1: 智能检索

```
用户问 → AI理解 → 03-wiki搜索 → 整合回答 → 来源追溯
```

**你只需要说**：
```
"帮我找..."
"有没有和XX相关的..."
"查一下XX"
```

---

### F2: 知识摄取 (Ingest)

```
放文件 → 01-raw/
    ↓
读取分析 → 提取概念/实体
    ↓
创建 → 03-wiki/sources/源摘要
    ↓
更新 → 03-wiki/concepts/概念页
    ↓
更新 → 03-wiki/entities/实体页
    ↓
记录 → 03-wiki/log.md
```

**你只需要说**：
```
"ingest [文件]"
"摄取 [文件名]"
```

---

### F3: 记忆系统 (MemoryOS)

```
添加记忆 → short_term (FIFO, 7条)
    ↓
淘汰晋升 → mid_term (热度, 1000条)
    ↓
持久沉淀 → long_term (知识库)
```

**你只需要说**：
```
"记住..."
"添加到记忆"
```

---

### F4: 健康检查 (Lint)

```
lint命令 → 检查孤立页面
    ↓
检查断链 → 检查矛盾
    ↓
检查过期 → 生成报告
```

**你只需要说**：
```
"lint"
"健康检查"
```

---

### F5: 知识图谱

```
03-wiki/
├── concepts/    → 概念定义
├── entities/   → 实体定义
├── sources/   → 源摘要
├── comparisons/ → 对比分析
└── index.md   → 总索引
```
