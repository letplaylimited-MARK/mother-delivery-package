## 第一章：价值体系 — 为什么要用

### 1.1 一句话

> **省时间 · 记得住 · 会学习 · 能传承**

### 1.2 解决的核心问题

| 痛点 | 传统方式 | Universal-KB |
|------|----------|---------------|
| 文件散乱 | 文件夹越建越多，要找的东西翻半天 | 统一入口 `01-raw/`，AI自动整理到 `03-wiki/` |
| 知识遗忘 | 学过的东西不做笔记就忘了 | AI长期记忆 `04-memory/`，三层MemoryOS引擎 |
| 经验流失 | 老手走了经验带走了 | 经验沉淀为 `03-wiki/` 知识图谱，新AI/新人直接查 |
| 重复劳动 | 同一种问题反复搜反复问 | 知识摄取一次，永久可查可复用 |
| AI协作断层 | 换个AI要重新教 | `05-agents/AGENTS.md` 一次性配置，全AI通用 |

### 1.3 投入产出比

```
┌──────────────────────────────────────────────┐
│  投入                                         │
│    ├─ 初始部署：5分钟（复制文件夹）             │
│    ├─ 日常使用：随手放文件                     │
│    └─ 定期维护：每周5分钟（lint检查）           │
│                                              │
│  产出                                         │
│    ├─ 找文件：1小时 → 3秒                      │
│    ├─ 知识整理：1小时 → 10分钟                  │
│    ├─ 经验传承：不可量化 → 随时可查             │
│    └─ AI对接：反复教 → 一次配置                │
│                                              │
│  投入1%，产出100%                               │
└──────────────────────────────────────────────┘
```

### 1.4 价值显现时间线

| 时间 | 你看到了什么 |
|------|-------------|
| 第1天 | 文件放到正确位置，心里有底 |
| 第1周 | 知识开始积累，`index.md` 有了内容 |
| 第1个月 | 经验和文档结构化沉淀，查找不再靠记忆 |
| 第3个月 | AI学会你的偏好，越来越懂你 |
| 第6个月 | 形成"第二大脑"，对答如流 |

### 1.5 适用人群

| 人群 | 怎么用 |
|------|--------|
| **个人知识管理** | 记笔记、整理资料、积累经验 |
| **AI项目开发者** | 管理AI项目知识库、Prompt资产 |
| **项目经理** | 沉淀项目文档、SOP、经验 |

## 第二章：功能体系 — 能做什么

### 2.1 五大核心功能速览

```
┌──────────────────────────────────────────────────┐
│  F1: 智能检索                     │
│  "查XX" → AI在03-wiki/中搜索     │
├──────────────────────────────────────────────────┤
│  F2: 知识摄取 (Ingest)            │
│  "ingest [文件]" → raw→wiki       │
├──────────────────────────────────────────────────┤
│  F3: 记忆系统 (MemoryOS)          │
│  "记住XX" → 自动存入三层记忆       │
├──────────────────────────────────────────────────┤
│  F4: 健康检查 (Lint)              │
│  "lint" → 诊断整库健康状况         │
├──────────────────────────────────────────────────┤
│  F5: 知识图谱                     │
│  结构化管理概念+实体+来源          │
└──────────────────────────────────────────────────┘
```

### 2.2 F1 - 智能检索

**一句话**: 像问朋友一样问AI，自动搜索知识图谱

**完整流程**:
```
你说："查一下R5+收入规则"
  ↓
AI理解：提取关键词 "R5+"、"收入规则"
  ↓
搜索：03-wiki/concepts/ → 03-wiki/entities/ → 03-wiki/sources/
  ↓
整合：找到相关页面，构建回答
  ↓
返回："R5+是关系等级≥5的主播，收入按6档兑换..."
  ↓
来源：附上引用路径 [[concepts/R5+收入]] [[entities/主播]]
```

**你可以这么说**:
```
"帮我找XX"
"有没有和XX相关的资料"
"查一下XX是什么"
"XX和XX有什么关系"
```

### 2.3 F2 - 知识摄取 (Ingest)

**一句话**: 文件放进去，AI自动变成结构化知识

**完整流程**:
```
你把文件放到 01-raw/
  ↓
你对AI说："ingest [文件名]"
  ↓
AI读取文件内容
  ↓
AI分析：提取核心概念、识别实体、找关联
  ↓
创建 03-wiki/sources/[文件摘要].md  ← 源摘要
  ↓
创建/更新 03-wiki/concepts/[概念].md  ← 概念页
  ↓
创建/更新 03-wiki/entities/[实体].md  ← 实体页
  ↓
更新 03-wiki/index.md  ← 图谱总索引
  ↓
记录 03-wiki/log.md  ← 活动日志
  ↓
反馈："已完成!"
```

**你可以这么说**:
```
"ingest 01-raw/平台制度V3.2.docx"
"摄取 01-raw/手册.pdf"
"盘点 01-raw/里的新文件"
```

### 2.4 F3 - 记忆系统 (MemoryOS)

**一句话**: AI的三层记忆，越用越懂你

**三层架构**:
```
ShortTermMemory（短期）
├── FIFO队列，最多7条
├── 你最近说的话
└── 新覆盖旧
     ↓ 被淘汰
MidTermMemory（中期）
├── 热度排序，最多1000条
├── 常用知识自动升温
└── 冷门知识自动降级
     ↓ 持续有热度
LongTermMemory（长期）
├── 持久化存储，最多100条
├── 核心经验和规则
└── 永不自动遗忘
```

**你可以这么说**:
```
"记住我习惯用Markdown写文档"
"添加到记忆：主播分级标准是R0-R7"
"sum"  → 查看记忆摘要
"忘记XX" → 删除指定记忆
```

### 2.5 F4 - 健康检查 (Lint)

**一句话**: 一键诊断知识库，像体检一样

**检查项**:
```
1. 孤立页面  → 没有被其他页面引用的页面
2. 断链     → 引用了不存在的页面
3. 矛盾     → 同一概念在不同页面说法不一致
4. 过期     → 超过30天未更新的页面
```

**你可以这么说**:
```
"lint"
"健康检查"
"检查一下知识库状态"
```

### 2.6 F5 - 知识图谱

**一句话**: 所有知识的索引地图

```
03-wiki/
├── concepts/     ← "这是什么"（概念定义）
│   ├── 三层架构.md
│   ├── Ingest流程.md
│   └── Lint检查.md
│
├── entities/     ← "谁/什么对象"（实体定义）
│   └── 系统.md
│
├── sources/      ← "从哪来的"（源摘要）
│   └── 框架说明.md
│
├── comparisons/  ← "有什么区别"（对比分析）
│   └── 传统-vs-Universal-KB.md
│
├── index.md      ← 总索引
└── log.md        ← 活动日志
```

## 第四章：运作体系 — In/Qu/Li/Me

### 4.1 全景运作图

```
你                                    AI
│                                     │
├─ 放文件到 01-raw/ ─────────────►  ingest
│                                     ├─ 分析文件
│                                     ├─ 写 sources/
│                                     ├─ 写 concepts/
│                                     ├─ 写 entities/
│                                     ├─ 更新 index.md
│                                     └─ 记录 log.md
│
├─ 问"查XX"  ────────────────────►  query
│                                     ├─ 搜索 wiki/
│                                     ├─ 关联上下文
│                                     └─ 返回+来源
│
├─ 说"记住XX" ───────────────────►  memory
│                                     ├─ 存 short_term
│                                     ├─ 晋升 mid_term
│                                     └─ 沉淀 long_term
│
├─ 说"lint"  ────────────────────►  lint
│                                     ├─ 检查孤立
│                                     ├─ 检查断链
│                                     ├─ 检查矛盾
│                                     └─ 生成报告
│
└─ 说"sum"  ─────────────────────►  记忆摘要
                                        └─ 返回记忆统计
```

### 4.2 Ingest 运作详解

**触发条件**: 你说 "ingest [文件]" 或 "摄取 [文件]"

**AI执行步骤**:
```
Step 1: 从 01-raw/ 读取文件
Step 2: 分析内容结构
Step 3: 提取核心概念 → 写到 03-wiki/concepts/
Step 4: 识别实体 → 写到 03-wiki/entities/
Step 5: 创建源摘要 → 写到 03-wiki/sources/
Step 6: 更新 index.md 总索引
Step 7: 记录到 log.md
```

**页面标准格式**:
```yaml
---
title: 页面标题
type: concept | entity | source-summary | comparison
sources: [01-raw/文件路径]
related: [03-wiki/页面路径]
created: 2026-04-21
updated: 2026-04-21
tags: [标签1, 标签2]
confidence: high | medium | low
---
```

**内部链接格式**:
```markdown
[[concepts/概念名]]    → 链接到概念页
[[entities/实体名]]   → 链接到实体页
[[sources/源摘要名]]   → 链接到源摘要
```

### 4.3 Query 运作详解

**触发条件**: 你问"这是什么？" / "找XX" / "XX和XX的关系"

**AI执行步骤**:
```
Step 1: 理解问题，提取关键词
Step 2: 先搜索 03-wiki/concepts/
Step 3: 再搜索 03-wiki/entities/
Step 4: 再搜索 03-wiki/sources/
Step 5: 构建答案，引用相关页面
Step 6: 如果找不到 → 诚实说明 + 建议摄取
```

### 4.4 Lint 运作详解

**触发条件**: 你说 "lint" 或 "健康检查"

**AI执行步骤**:
```
Step 1: 检查孤立页面
        → 遍历所有页面，找没有被引用的
Step 2: 检查断链
        → 遍历所有 [[ ]] 链接，找指向不存在的页面
Step 3: 检查矛盾
        → 同一概念在不同页面的定义是否一致
Step 4: 检查过期
        → 超过30天未更新的页面
Step 5: 生成报告到 log.md
```

### 4.5 Memory 运作详解

**触发条件**: 你说 "记住XX" / 对话中产生的记忆

**AI执行步骤**:
```
Step 1: add_memory(内容)
        → 存入 short_term/
        → FIFO队列，满7条淘汰最旧的
Step 2: 淘汰的进入 mid_term/
        → 热度排序，访问多的保留
        → 热度低的逐渐下沉
Step 3: 高热度晋升 long_term/
        → 持久化存储
        → 永不遗忘
```

## 第五章：用户场景

### 场景一：个人知识管理

**用户画像**: 你是一名运营人员，每天接触大量文档

**你的日常**:
```
早上  -> 收到一份新的"平台制度V3.2.docx"
    -> 放到 01-raw/
    -> 说："ingest 平台制度V3.2.docx"
    -> AI自动整理到 03-wiki/

中午  -> 需要查"主播提成怎么算"
    -> 说："查主播提成"
    -> AI返回提成档位表 + 计算公式
    -> 附带来源路径

晚上  -> 学到新经验"新人前3周有保底"
    -> 说："记住新人前3周保底5.0 USD/W"
    -> AI存入记忆

每周  -> 说："lint"
    -> AI检查断链/孤立/过期
    -> 生成健康报告
```

**效果**: 1周后你的知识库自动建立，3个月后形成第二大脑

### 场景二：AI项目开发

**用户画像**: 你在开发AI聊天话术系统

**你的日常**:
```
项目开始  -> 把需求文档、设计文档放入 01-raw/
    -> "ingest AI话术需求文档.docx"
    -> "ingest AI话术设计文档.docx"
    -> AI分析出: concepts/话术类型, entities/主播...
    -> 自动建立关联

开发中  -> 查"话术推荐的触发条件"
    -> AI返回需求文档原文+设计文档对应章节
    -> 不用翻文件

修改  -> 说："记住：话术推荐按F1触发"
    -> 存入长期记忆
    -> 下次开发直接调出

交接  -> 新AI接入
    -> 读取 AGENTS.md + 03-wiki/
    -> 马上理解项目全貌
```

**效果**: 项目资料不会丢，AI切换零成本

### 场景三：团队协作

**用户画像**: 你们团队有多个运营人员

**你的日常**:
```
新人入职  -> 复制一份 Universal-KB/
    -> 新人AI读 AGENTS.md
    -> 新人查询知识库
    -> 老手的经验可以直接复用

共享知识  -> 在 01-raw/ 里放"新师傅扶持手册.pdf"
    -> 摄取后 03-wiki/ 新增"新师傅扶持"概念
    -> 所有人都可以查

经验传承  -> 记住"新人最容易在入职第2周流失"
    -> AI沉淀到长期记忆
    -> 新人接手时AI自动提醒防范
```

**效果**: 经验可复制，团队知识标准化

### 场景四：跨AI切换

**用户画像**: 你在ChatGPT/Qwen/Claude之间切换

**你的日常**:
```
统一配置  -> 05-agents/AGENTS.md 对所有AI生效
    -> 所有AI读取同样的配置文件
    -> 行为一致

迁移数据  -> 03-wiki/ 是标准Markdown
    -> 任何AI都能读取
    -> 知识不绑定某个AI

指令统一  -> "ingest" / "查XX" / "lint"
    -> 全部AI通用
    -> 不需要学多个口令
```

**效果**: 想用哪个AI用哪个，知识迁移零摩擦

cp -r /原始路径/Universal-KB /目标路径/Universal-KB

```
你的AI已经有了Universal-KB框架。
请说"初始化"让AI读取配置文件并开始工作。

**Step 3**: 开始使用
```
放一个文件到 01-raw/，然后说：
"ingest [文件名]"
```

启动后执行以下命令确认系统完整：

```

全部通过 → ✅ 系统就绪

## 第九章：常见问题

### Q1: 文件已经放在 01-raw/ 了，AI没有反应？

**回答**: 需要主动触发 Ingest。你说："ingest [文件名]"，AI才会执行摄取流程。

### Q2: 可以修改 03-wiki/ 下的文件吗？

**回答**: 可以。03-wiki/ 是可编辑层，你可以直接修改Markdown内容。修改后记得说"更新索引"让 index.md 同步。

### Q3: 记忆能删吗？

**回答**: 能。说"忘记 [内容]"就会从memory系统中删除。

### Q4: 文件夹可以改名吗？

**回答**: 建议不要改。AI的AGENTS配置里写死了 `01-raw/`、`03-wiki/` 这些路径。如果要改，需要同步更新 AGENTS.md。

### Q5: 内存会不会太大？

**回答**: 不会。MemoryOS有自动淘汰机制，short_term 最多7条，mid_term 最多1000条，long_term 最多100条。

### Q6: 换AI要用同一个知识库怎么办？

**回答**: 直接让新AI读取 `README.md` 和 `05-agents/AGENTS.md`，路径不变，数据不丢。

### Q7: 支持哪些文件格式？

**回答**: AI能读取的任何格式均可：Markdown、TXT、JSON、YAML、Word文档、PDF、代码文件等。

### Q8: 需要安装Python才能用吗？

**回答**: 不需要。MemoryOS引擎（memoryos.py）是可选增强功能。核心功能（raw→wiki→memory）全部由AI驱动，不需要安装任何环境。
