# 结构体系 - 怎么组织 Universal-KB

> **版本**: V1.0 | **更新时间**: 2026-04-21

---

## 完整目录结构

```
Universal-KB/
│
├── 01-raw/               ← Layer 1: 原始资料（只读）
│                           → 放入待处理的文件
│
├── 02-processed/         ← 处理后数据（临时）
│                           → 处理中的中间文件
│
├── 03-wiki/              ← Layer 2: 知识图谱（核心）
│   ├── concepts/          → 概念定义（3页面）
│   ├── entities/          → 实体定义（1页面）
│   ├── sources/           → 源摘要
│   ├── comparisons/       → 对比分析
│   ├── index.md           → 图谱总索引
│   └── log.md            → 活动日志
│
├── 04-memory/            ← Layer 3: 长期记忆
│   ├── memoryos.py       → MemoryOS引擎
│   ├── config.yaml       → 配置参数
│   ├── short_term/       → 短期记忆（FIFO）
│   ├── mid_term/        → 中期记忆（热度）
│   └── long_term/       → 长期记忆（持久）
│
├── 05-agents/            ← AGENTS配置
│   └── AGENTS.md        → AI行为规范
│
├── 06-output/            ← 输出成果
│                           → 报告/导出文件
│
├── docs/                 ← 文档
│   ├── 价值体系.md       → 为什么要用
│   ├── 功能体系.md       → 能做什么
│   ├── 结构体系.md       → 怎么组织  ← 本文件
│   ├── 三体体系.md       → 体系关系
│   └── architecture.md  → 架构详情
│
└── README.md             → 项目说明
```

---

## 三层架构

```
Layer 1: 01-raw/        = 原始资料（不可变）
          ↓ Ingest
Layer 2: 03-wiki/       = 知识图谱（可编辑）
          ↓ Query
Layer 3: 04-memory/    = 长期记忆（持久化）
          ↓ 配置
Layer 4: 05-agents/     = AGENTS规范（行为）
```

---

## 数据流

```
用户输入
    ↓
01-raw/（接收文件）
    ↓  Ingest流程
03-wiki/（知识结构化）
    ├─ sources/（源摘要）
    ├─ concepts/（概念）
    └─ entities/（实体）
    ↓  Query流程
04-memory/（记忆沉淀）
    ├─ short_term（短期）
    ├─ mid_term（中期）
    └─ long_term（长期）
    ↓  AGENTS规范
05-agents/AGENTS.md
    ↓  输出
06-output/
```

---

## 命名规范

```
目录：编号-名称（如 01-raw/）
文件：主题-描述.md
```
