## 每个文件夹的定义与工作流

---

### 1. `01-raw/` — 原始资料层（入口）

| 属性 | 说明 |
|------|------|
| **定义** | 原始文件收件箱，所有待处理的知识原材料 |
| **操作者** | **你** — 手动放入文件 |
| **读写规则** | AI只读不修改 |
| **支持格式** | 任何AI可读的格式 (md/txt/docx/pdf/json等) |

**工作流**:
```
你放入文件 → 口头触发 "ingest [文件名]" → AI读取分析 → 进入下一层
```
**现状**: 含 `平台运营制度V3.2.md`（本次模拟放入）

### 2. `02-processed/` — 临时处理层（缓冲区）

|------|------|

| **操作者** | AI自动管理 |
| **读写规则** | 临时存储，处理完毕后可清理 |

**工作流**:

Ingest过程中 → 解析/转换的中间产物暂存 → 完成后转入03-wiki/ → 本目录自动清空

### 3. `03-wiki/` — 知识图谱层（核心）

| 属性 | 说明 |
|------|------|
| **定义** | 结构化的知识中心，所有经过整理的信息 |
| **操作者** | AI维护 + **你可以**直接编辑 |
| **读写规则** | 可编辑，持续优化 |

**子目录定义**:

| 子目录 | 定义 | 类比 | 现状 |
|--------|------|------|------|
| `concepts/` | **概念** — "这是什么"，知识定义 | 百科词条 | 7页（三层架构/Ingest/Lint/主播分级/收入结算/违规处罚/推荐算法） |
| `entities/` | **实体** — "谁/什么对象"，具体事物 | 人物档案 | 2页（系统/主播） |
| `sources/` | **来源** — "从哪来的"，原始资料摘要 | 读书笔记 | 2页（框架说明/平台运营制度V3.2） |
| `comparisons/` | **对比** — "有什么区别"，多方案比较 | 优缺点分析 | 1页（传统vs Universal-KB） |
| `index.md` | **总索引** — 知识图谱的目录 | 图书馆索引卡 | 存在 |
| `log.md` | **活动日志** — 所有操作记录 | 操作日记 | 存在 |

**工作流**:
```
Ingest流入:
  01-raw文件 → concepts/提取概念 + entities/识别实体 → sources/写摘要
  → index.md更新索引 → log.md记录日志

Query流出:
  用户提问 → concepts搜 → entities搜 → sources搜 → 整合回答+来源
```

---

### 4. `04-memory/` — 长期记忆层（AI大脑）

| 属性 | 说明 |
|------|------|
| **定义** | AI的三层记忆系统，越用越懂你 |
| **操作者** | memoryos.py引擎自动管理 |
| **读写规则** | 全自动，按FIFO/热度/晋升算法流转 |

**文件定义**:

| 文件/目录 | 定义 |
|-----------|------|
| `memoryos.py` | MemoryOS引擎核心代码 (8190B) — 三层记忆架构实现 |
| `config.yaml` | 配置参数 — 容量/热度阈值/衰减因子 |
| `short_term/` | **短期记忆** — FIFO队列，容量7条，最新对话/经验 |
| `mid_term/` | **中期记忆** — 热度排序，容量1000条，常用知识自动升温 |
| `long_term/` | **长期记忆** — 持久化存储，容量100条，永不遗忘（分 `knowledge/` + `strategies/`） |

**工作流**:
```
用户说"记住XX"
  ↓
add_memory() → short_term (FIFO, 满7淘汰最旧)
  ↓ 淘汰
mid_term (热度驱动, heat≥5.0晋升, 低于阈值淘汰)
  ↓ 晋升
long_term (持久化JSON文件, 分知识和策略两类)
```

## 最佳方案决策

**原则**: 交付给用户的框架 = 框架自身说明 + 空容器，不含任何模拟数据

### 保留的内容（框架必备）

| 类别 | 内容 | 为什么保留 |
|------|------|-----------|
| **框架自描述知识图谱** | 三层架构 / Ingest流程 / Lint检查 / 系统 / 框架说明 / 传统vs对比 | AI读取后理解框架运作方式 |
| **全量文档** | docs/ 下8份文档 | 用户查阅使用 |
| **引擎+配置** | memoryos.py / config.yaml / AGENTS.md | 功能核心，零配置即用 |
| **目录骨架** | 01-raw~06-output 全部空目录 | 用户直接使用 |

### 清除的内容

| 内容 | 原因 |
|------|------|
| `01-raw/平台运营制度V3.2.md` | 模拟测试数据，与用户无关 |
| 03-wiki 下6个模拟页面（主播分级/收入结算/违规处罚/推荐算法/主播/平台运营制度源摘要） | 防止用户资料混淆 |
| `3份污染文件`（Prompt卡片/清理流程/会话记录） | 系统级数据污染 |
| `index.md/log.md` 中的模拟记录 | 恢复纯净框架历史 |
