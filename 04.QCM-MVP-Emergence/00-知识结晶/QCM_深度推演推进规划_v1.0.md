## 二、深度推演: 核心问题分析

### 2.1 公式层面: R < 0.85 的真实瓶颈

```
论文公式  : R = 0.30*K + 0.35*C + 0.20*I - 0.15*E
当前公式  : R = 0.35*K + 0.40*C + 0.25*I           (W_E=0妥协)

当我们恢复论文权重:
  Max R = 0.30*1.0 + 0.35*0.857 + 0.20*1.0 - 0.15*0.0
        = 0.30 + 0.300 + 0.20
        = 0.80

差距 = 0.85 - 0.80 = 0.05
```

**根因**: 8角色系统天生限制了C_comp上限

### 2.2 论文原始设计意图

```
论文设计的是"角色配对系统":
  - 127对工作对校准
  - 每对工作对有特定的技能组合
  - 不同配对有不同的C值
  - 涌现需要"高互补性"的角色配对

而非"固定2角色系统":
  - 当前Secretary-Researcher只有4个技能
  - C=1-1/7=0.857
  - C的极限被设计锁死
```

### 2.3 缺失的链路: F7动态权重

```
论文公式链: F1 → F7 → F19 → F20

F7: w_t = w_(t-1) + λ*(R - R_target)*e^(-k*t)*g_i

F7的作用:
  - 当R接近0.85时,动态调整权重
  - 自动增加K、C、I的正贡献
  - 降低E的负贡献
  - 这是系统自适应的核心机制

当前完全缺失! 我们手动改了W_E=0代替F7
```

### Phase 1 — F7动态权重 (2-3天)

**目标**: 实现F7公式，让系统自动调整权重

```
操作清单:
[ ] 实现F7: w_t = w_(t-1) + λ*(R - R_target)*e^(-k*t)*g_i
[ ] λ学习率: 0.01 (初始)
[ ] R_target: 0.85
[ ] g_i: 各权重的个体增长因子
    - g_K: 1.2 (K增长潜力大)
    - g_C: 0.5 (C被设计锁定)
    - g_I: 1.0 (I增长有限)
    - g_E: -1.5 (E应快速下降)
[ ] k衰减: 0.1 (随时间收敛)
[ ] 验证F7能自动调整使R达到0.85
```

**关键技术点**:
```
F7中的g_i是关键设计：
  g_K = 1.2  → K通过飞轮增长，权重应增加
  g_C = 0.5  → C固定，权重应稳定  
  g_E = -1.5 → E应降为0，权重应归零

这样系统自动学会："E不重要了，K才重要"
而不是手动设置W_E=0
```

**退出标准**: 系统通过F7自我调整，R达到0.85+

## 四、关键技术决策

### 4.1 为什么选F7而不是W_E=0

```
W_E=0 (妥协方案):
  优点: 快速验证R>0.85
  缺点: 偏离论文，不优雅

F7动态权重 (论文方案):
  优点: 符合论文设计，自适应
  缺点: 实现复杂，需调参

结论: Phase 0修复 → Phase 1实现F7
```

### 4.2 为什么先8角色再飞轮

```
先8角色:
  - 发现更好的配对，降低C瓶颈
  - 配对矩阵指导飞轮设计
  - 为F19-F20提供输入数据

后飞轮:
  - 基于实际配对数据
  - 调参更精准
  - 飞轮效果更可预测
```

### 4.3 最终架构

```
论文公式(Phase 0)
  └→ F7动态权重(Phase 1)
       └→ 8角色配对(Phase 2)
            └→ F19-F20飞轮(Phase 3)
                 └→ 涌现触发
                      └→ 系统化(Phase 4)
```
