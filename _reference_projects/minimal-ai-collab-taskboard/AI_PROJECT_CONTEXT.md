# AI Project Context

## Project

`minimal-ai-collab-taskboard` is a small offline reference project for the mother package. It shows how a general AI model and a developer can preserve route decisions, validation anchors, and delivery evidence while implementing a bounded feature.

## Scope

- Validate deterministic task cards in JSON.
- Require `route_feedback`-style fields in each card.
- Provide a runnable smoke test.
- Keep USER_PACK as a template, not a place for sample-project code.

## Out Of Scope

- No external model calls.
- No database.
- No web server.
- No mutation of `03` or `05` submodules.

## Entrypoints

- `docs/PRD.md`
- `docs/SPEC.md`
- `tasks/TASKS.md`
- `tests/TEST_PLAN.md`
- `tests/test_smoke.py`
- `VERIFY-DELIVERY.ps1`
